# Music Class Notes & Recordings

This is a simple static website for sharing music class notes and audio recordings.

## Run locally

Open `index.html` directly in a browser, or use a simple local server if you prefer.

## Add your own recordings

1. Put audio files in the `recordings/` folder.
2. Update the `<source src="...">` paths in `index.html`.
3. Keep file names short and consistent, like `class-2026-08-19.mp3`.

## Host on GitHub Pages

1. Create a new GitHub repository.
2. Upload these files to the repository root.
3. In GitHub, go to the repository settings.
4. Open the Pages section.
5. Set the source to the `main` branch and the root folder.
6. Save, then wait for GitHub Pages to publish the site.

## Notes

- GitHub Pages works best for a static site like this.
- If your recordings are large, compress them to keep the repository manageable.
